# Workforce Intelligence Dashboard

## 📌 Project Overview

The Workforce Intelligence Dashboard is an HR analytics project designed to analyze employee data and provide insights into workforce composition, demographics, salary distribution, employee performance, and hiring and termination trends.

Using Python for data analysis and Tableau for visualization, this project explores workforce patterns across departments, job roles, and locations through interactive dashboards and key HR performance indicators (KPIs).

## 🎯 Project Objectives

- Analyze workforce demographics and employee composition.
- Examine salary distribution across different employee groups.
- Evaluate employee performance patterns.
- Track hiring and termination trends over time.
- Compare workforce metrics across departments, job roles, and locations.
- Develop an interactive dashboard to support HR analysis and reporting.

## 🛠️ Tools & Technologies

- **Python:** Data cleaning, data preparation, and exploratory data analysis.
- **Tableau:** Interactive dashboard development and data visualization.
- **Excel/CSV:** Dataset handling (if applicable).

## 📊 Dataset Overview

- **Total Records:** 8,950 employee records.
- **Domain:** Human Resources (HR Analytics).
- **Key Areas:** Employee demographics, salaries, performance, hiring, terminations, departments, job roles, and locations.

## 📈 Dashboard Features

The dashboard is organized into three main sections:

### 1. Overview
- Total employee count.
- Hired employees.
- Active and non-active employees.
- Workforce distribution.
- Hiring and termination trends.

### 2. Demographics
- Workforce distribution by gender and age groups.
- Employee composition across departments and job roles.
- Workforce distribution across locations.

### 3. Income
- Salary distribution across employee groups.
- Income comparisons by department and job role.
- Analysis of compensation patterns.

### 4. Employee Records
- Detailed employee-level information.
- Interactive filters to explore workforce records.
- Employee-level data exploration.

## 🔍 Key Analysis Areas

- Workforce composition and demographics.
- Salary and compensation distribution.
- Employee performance analysis.
- Hiring and termination patterns.
- Department-wise and job-role-wise comparisons.
- Headquarters vs. branch workforce analysis (New York HQ and other locations).

- HR KPI analysis.
- Data visualization and dashboard development.

- Business-focused data analysis and reporting.
